# Мобильное приложение «Байт»

Кроссплатформенное приложение для студентов НГТУ НЭТИ. Клиент показывает чат, список дел, заметки, сервисы и профиль. Данные учётной записи, кабинета и ленты уведомлений приходят с [бэкенда](../backend/README.md).

Общее описание проекта: [README в корне](../README.md).

    │   └── (tabs)/

## Установка

Нужны Node.js 18+ и npm.

```bash
cd frontend
npm install
```

Зафиксированное дерево зависимостей лежит в `package-lock.json`, поэтому установка выполняется через npm.

## Запуск

```bash
npx expo start
```

Та же команда записана как `npm start`.

После старта Metro предлагает варианты:

| Действие | Результат |
| --- | --- |
| QR-код в приложении Expo Go | Открытие проекта на телефоне |
| Клавиша `a` | Эмулятор Android (`npm run android` вызывает `expo run:android`) |
| Клавиша `i` | Симулятор iOS на macOS (`npm run ios`) |
| Клавиша `w` или `npm run web` | Веб-сборка, `expo start --web` |

Телефон и компьютер должны быть в одной сети. На Android приложение само по себе не ходит на `localhost` компьютера: в `src/api/config.ts` для Android задан хост `192.168.50.100` и порт `8000`. На iOS и в вебе по умолчанию используется `http://localhost:8000`.

Сменить хост: долгое нажатие на вкладку «Чат». В окне вводится IP компьютера, порт остаётся `8000`.

## Сборка

Сборка APK/AAB выполняется через EAS Build (конфигурация eas.json настроена).

Внутренняя сборка Android:

```bash
npx eas-cli build --platform android --profile preview
```

Сборка профиля `production` (в конфиге включён `autoIncrement`):

```bash
npx eas-cli build --platform android --profile production
```

Профиль `development` собирает клиент разработки (`developmentClient: true`) для внутренней установки.

Локальная отладочная сборка без EAS:

```bash
npx expo run:android
```

## Конфигурация

Отдельного `.env` у клиента нет. Адрес API:

| Параметр | Где задан | Значение |
| --- | --- | --- |
| Порт | `API_PORT` в `src/api/config.ts` | `8000` |
| Хост Android | `DEFAULT_API_HOST` | `192.168.50.100` |
| Хост iOS и веба | `defaultApiUrl()` | `localhost` |
| Свой хост | AsyncStorage, ключ `@custom_api_ip` | вводит пользователь |

Перед запуском на телефоне замените `192.168.50.100` на IP компьютера, где слушает Uvicorn, либо сохраните его через долгое нажатие на «Чат». Сервер должен быть запущен с `--host 0.0.0.0`.

Ключ GigaChat и `SECRET_KEY` в клиент не кладутся. Их читает только бэкенд.

Идентификатор проекта EAS указан в `app.json` → `extra.eas.projectId`.

## Основные экраны

Приложение открывается сразу на вкладке «Чат». Вход в аккаунт не блокирует первый запуск: гость пользуется локальными данными, а стена авторизации находится в профиле.

| Экран | Маршрут | Что делает |
| --- | --- | --- |
| Сервисы | `/(tabs)/services` | Сетка блоков помощника. «Трекер дел» и «Достижения» открывают экраны. Остальные плитки сообщают, что сервис появится позже |
| Список дел | `/(tabs)/todos` | Проекты, разделы, задачи и календарь. Без входа данные остаются на устройстве |
| Чат | `/(tabs)/chat` | Диалог с «Байтом» через `POST /ask`. Кризисные формулировки заменяются сообщением со службой психологической поддержки НГТУ |
| Заметки | `/(tabs)/notes` | Текстовые заметки. На сервере для вошедшего пользователя доступна автокатегория |
| Профиль | `/(tabs)/profile` | Имя и группа, импорт личного кабинета, режим дня, PIN и биометрия, сессии, смена пароля, двухфакторная почта |
| Уведомления | `/(tabs)/profile/notifications` | Лента карточек: задачи, напоминания, пожелания. Колокольчик доступен с вкладок |
| Факты | `/(tabs)/profile/facts` | Список фактов, которые приложение сохранило о студенте. Доступен после входа |
| Статистика | `/(tabs)/statistics` | Успеваемость, задолженности, прогресс и ручные баллы. Открывается из «Сервисов» и профиля, в нижней панели скрыта |
| Вход | `/(tabs)/profile/auth` | Регистрация и вход. Сессия не обязательна для старта приложения |
| Сессии | `/(tabs)/profile/sessions` | Список активных входов |
| Блокировка | поверх интерфейса | PIN при холодном старте, если код задан в профиле |

## Зависимость от бэкенда

Клиенту нужен сервер из [backend/README.md](../backend/README.md) по адресу `http://<хост>:8000`.

Если бэкенд не запущен или указан чужой IP:

- чат не получает ответ модели;
- импорт личного кабинета, лента уведомлений, факты и серверные заметки недоступны;
- вход и регистрация завершаются ошибкой сети;
- гостевые дела, заметки и предметы по-прежнему читаются и пишутся в память телефона;
- в интерфейсе виден признак офлайна, когда устройство без сети.

Сервер при этом должен слушать `0.0.0.0:8000`, а брандмауэр Windows должен пропускать входящие подключения на порт 8000. Если адрес по умолчанию из эмулятора недоступен, укажите IP компьютера в окне смены сервера.
