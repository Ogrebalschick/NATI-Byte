# Байт

Персональный цифровой помощник студента НГТУ НЭТИ. Приложение собирает расписание, оценки, дела и заметки в одном месте и помогает не терять учебные сроки.

«Байт» рассчитан на студента, которому нужно одновременно следить за личным кабинетом, дедлайнами и нагрузкой в течение семестра. Вместо разрозненных сервисов университета и заметок в мессенджере проект даёт мобильный клиент и серверное API.

## Основные возможности

- **Push-уведомления.** Утренние и вечерние карточки по личному режиму дня (по умолчанию 08:00 и 22:30, часовой пояс Новосибирска). В утренней карточке учитывается погода: при дожде добавляется напоминание про зонт. Напоминания о занятиях реализованы в виде push-уведомлений (интеграция с динамическим расписанием в разработке).
- **Трекер дел.** Проекты, разделы, задачи, календарь и отметка просрочки. Отдельные реакции «похвала / мотивация / возмущение» в экране задач в коде не выделены. Поддержка за выполненные дела есть в вечерней карточке уведомлений.
- **Достижения.** Экран статистики по данным личного кабинета: успеваемость, академические задолженности, индивидуальный прогресс, а также ручной учёт баллов по предметам.
- **Письма счастья.** Уведомления от деканата. Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Цели.** Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Активный досуг в Новосибирске.** Кино, театры, музеи, парки, секции НГТУ. Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Вечер для себя.** Подбор книг по настроению. Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях). В вечерней карточке уже предлагается почитать или включить спокойную музыку.
- **Слово дня («А ты в курсе?»).** Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Рейтинг группы.** Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Погода.** Прогноз для Новосибирска запрашивается у Open-Meteo и используется в утреннем пожелании. Отдельный экран погоды ещё не открывается.
- **Флудилка.** Шаурма, рецепты, рекомендации. Интерфейс экрана реализован, демонстрационное наполнение (полная интеграция данных планируется в следующих версиях).
- **Кризисные формулировки в чате.** При выявлении тревожных маркеров в тексте приложение не генерирует стандартный ответ, а немедленно выводит контакты службы психологической поддержки НГТУ.

На вкладке «Сервисы» открываются «Трекер дел» и «Достижения». У остальных сервисов интерфейс экрана реализован с демонстрационным наполнением; полная интеграция данных планируется в следующих версиях.

## Быстрый старт

Нужны два процесса: сервер и клиент.

1. Клонировать репозиторий и перейти в него.
2. Поднять API по инструкции [backend/README.md](backend/README.md). Проверка: [http://localhost:8000](http://localhost:8000) и [http://localhost:8000/docs](http://localhost:8000/docs).
3. Запустить приложение по инструкции [frontend/README.md](frontend/README.md).
4. На телефоне в одной сети с компьютером указать IP сервера. На Android адрес по умолчанию — `http://192.168.50.100:8000`. Долгое нажатие на вкладку «Чат» открывает окно смены адреса.

## Установка и запуск

```bash
git clone <URL репозитория GitLab>
cd NATI-Byte
```

Сервер:

```bash
cd backend
python -m venv venv
```

Windows (PowerShell):

```powershell
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

macOS и Linux:

```bash
source venv/bin/activate
pip install -r requirements.txt
uvicorn main:app --reload --host 0.0.0.0 --port 8000
```

Клиент, из каталога `frontend`:

```bash
cd frontend
npm install
npx expo start
```

Флаг `--host 0.0.0.0` нужен, чтобы телефон в локальной сети видел компьютер. Порт клиента Metro и порт API разные: API слушает `8000`.

## Конфигурация

Секреты хранятся в `backend/.env`. Файл не коммитится. Пример:

```env
GIGACHAT_CREDENTIALS=ключ_из_личного_кабинета_GigaChat
SECRET_KEY=длинная_случайная_строка
DATABASE_URL=sqlite:///./byte.db

SMTP_HOST=smtp.mail.ru
SMTP_PORT=465
SMTP_USE_SSL=True
SMTP_USE_TLS=False
SMTP_USER=почта@mail.ru
SMTP_PASSWORD=пароль_приложения
SMTP_FROM=почта@mail.ru
```

| Переменная | Обязательна | Назначение |
| --- | --- | --- |
| `SECRET_KEY` | да | Подпись JWT (HS256). Без неё процесс не стартует |
| `GIGACHAT_CREDENTIALS` | для чата, заметок, разбора кабинета и карточек | Ключ доступа к GigaChat |
| `DATABASE_URL` | нет | Строка SQLAlchemy. По умолчанию `sqlite:///./byte.db` |
| `SMTP_HOST`, `SMTP_PORT`, `SMTP_USER`, `SMTP_PASSWORD` | для писем с кодом | Почта регистрации, входа и смены пароля. `SMTP_PASS` принимается как старое имя пароля |

В мобильном клиенте отдельного `.env` нет. Базовый URL задаётся в `frontend/src/api/config.ts`: порт `8000`, на Android хост `192.168.50.100`, на остальных платформах `localhost`. Свой хост сохраняется на устройстве.
